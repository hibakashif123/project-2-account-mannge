# Bank Account Manager

A simple bank account simulator that demonstrates exception handling in Python.

## Features
- Create a bank account with name and balance
- Deposit money
- Withdraw money (with validation)
- Check balance

## Error Handling
- ValueError: Catches non-numeric input
- Custom validation: Checks for negative amounts, balance limits, etc.
- Friendly error messages instead of crashes
